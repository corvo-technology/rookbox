`desktop`, `corvo-computer` and their `-v2` versions run a Linux desktop with Chromium. You see and control the screen in the browser over VNC, with nothing to install.

## Open it

In the [Dashboard](https://app.rookbox.run), open the machine and click **Open desktop**. From the CLI:

```sh
rookbox desktop <id>
```

The first open can take a few seconds.

## How it works

- The Dashboard generates a signed link that is valid for 2 minutes.
- The link starts a desktop session of up to 4 hours.
- The desktop is served from its own origin (`desk.rookbox.run`), separate from the Dashboard.
- The machine's token never reaches the browser.

`seed` machines have no screen. See [Templates](/en/concepts/templates/).

## When to use it

To watch an agent that drives the browser, or to do a manual login the agent continues afterwards. The [Browser agent](/en/guides/browser-agent/) guide shows the flow.
