## E2B SDK

Only two.

| Variable | Value | What for |
| --- | --- | --- |
| `E2B_API_KEY` | `rbx_...` | Your Rookbox API key. |
| `E2B_API_URL` | `https://api.rookbox.run` | The API address. |

```sh
export E2B_API_KEY=rbx_...
export E2B_API_URL=https://api.rookbox.run
```

Do not set other E2B variables. The SDK finds where the machine is from the API's answer.

## CLI

The CLI uses the credential saved by `rookbox login`. For CI, where there is no interactive login, use the SDK with the two variables above.
