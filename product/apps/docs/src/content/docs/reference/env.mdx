## SDK da E2B

São só duas.

| Variável | Valor | Para quê |
| --- | --- | --- |
| `E2B_API_KEY` | `rbx_...` | Sua chave de API do Rookbox. |
| `E2B_API_URL` | `https://api.rookbox.run` | O endereço da API. |

```sh
export E2B_API_KEY=rbx_...
export E2B_API_URL=https://api.rookbox.run
```

Não defina outras variáveis da E2B. O SDK descobre sozinho onde a máquina está, pela resposta da API.

## CLI

A CLI usa a credencial salva pelo `rookbox login`. Para o CI, onde não há login interativo, use o SDK com as duas variáveis acima.
